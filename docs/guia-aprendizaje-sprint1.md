# 📘 Guía de Aprendizaje - Sprint 1: El Despegue del Onboarding

¡Bienvenidos al **Sprint 1**! Durante este ciclo nos enfocaremos en construir la historia de usuario de **Experiencia de Bienvenida y Onboarding Interactivo**. Esta guía te ayudará a dominar los conceptos técnicos, de diseño y metodológicos necesarios para triunfar.

---

## 🎯 Objetivos de Aprendizaje

1. **Dominio del Frontend Moderno:** Comprender cómo gestionar estados locales en componentes interactivos usando JavaScript y frameworks modernos.
2. **Colaboración Ágil con Git y GitHub:** Aprender el flujo de trabajo mediante ramas, Pull Requests y la correcta asignación de Codeowners.
3. **Enfoque en el Usuario (UX/UI):** Diseñar interfaces accesibles y atractivas que reduzcan la fricción inicial y enamoren a los nuevos visitantes.

---

## 🛠️ Temas Clave a Estudiar

### 1. Gestión de Estado y Persistencia (`localStorage`)
Para evitar que el tutorial interactivo aparezca cada vez que el usuario recarga la página, aprenderemos a utilizar el almacenamiento del navegador:
* ¿Cómo usar `localStorage.getItem()` y `localStorage.setItem()`?
* Buenas prácticas para limpiar o validar datos temporales en el lado del cliente.

### 2. Diseño Responsivo y Accesibilidad
El onboarding debe verse perfecto en cualquier dispositivo:
* Uso avanzado de **Flexbox** y **CSS Grid** (o clases utilitarias de Tailwind CSS).
* Consideraciones de accesibilidad básica (uso de etiquetas semánticas y contraste de colores).

### 3. Flujo de Trabajo en equipo
* ¿Cómo abrir una Pull Request correctamente desde una rama de características (*feature branch*)?
* Cómo etiquetar a los revisores correctos siguiendo las reglas de la organización.
